## Ручная проверка на часах

1. `adb install -r vplayer-0.3.0.apk`, запустить «Мне нравится», нажать трек.
2. Выключить экран на 5+ минут — музыка должна играть и переходить к следующим трекам.
3. Нажать кнопку часов (выход на циферблат) — музыка продолжается.
4. В «Мне нравится» нажать «⬇ Скачать для оффлайна», дождаться «✓ Скачано».
5. Включить авиарежим / отключить сеть — «Скачанное» → плейлист → воспроизведение.
6. При проблемах: `adb logcat -d -s PlaybackService:* WM-WorkerWrapper:*` и
   `adb shell dumpsys activity services com.victormuha.vplayer`.
